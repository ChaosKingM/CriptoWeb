# Escribir y editar

## Empezar a escribir

- **Toca cualquier punto del texto** de una nota: se abre la escritura con el cursor justo en ese lugar.
- **Toca la gota del lápiz** (abajo, del lado de tu mano): escribe al final de la nota. En el diario, crea una entrada nueva con la hora actual.
- Para **dejar de escribir**, toca otra vez la gota del lápiz o usa el botón «atrás» del teléfono. Lo escrito se guarda solo.

## Formato (Markdown)

Mientras escribes, **mantén el dedo sobre la gota del lápiz**: se despliegan las opciones de formato. Desliza el dedo hasta una y suelta para aplicarla:

| Opción | Qué hace |
|---|---|
| B | negrita |
| I | cursiva |
| H | título |
| • | lista con viñetas |
| 1. | lista numerada |
| ☐ | casilla de tarea (`- [ ]`) |
| ❝ | cita |
| </> | código |
| ▦ | tabla |
| [[ ]] | enlace a otra nota |
| — | línea separadora |

Las notas son archivos Markdown (`.md`) normales: se pueden abrir con cualquier editor, por ejemplo Obsidian en la computadora.

## Enlaces entre notas

Escribe `[[Nombre de la nota]]` para enlazar otra nota. Los enlaces se ven en el [[10 Mapa de notas]].

## Mejorar el texto

Bajo cada sección hay un botón **Mejorar**. La IA propone una versión con la ortografía y la gramática corregidas, sin cambiar el sentido ni el tono. Tú decides si la usas. Los botones Mejorar caen hacia el lado de tu mano.

## Tiempo de escritura

Arriba, junto al título, un reloj cuenta los minutos que llevas escribiendo en esa nota.

## Dictar

Para dictar, usa el micrófono del teclado del teléfono: lo que digas se escribe como texto.
